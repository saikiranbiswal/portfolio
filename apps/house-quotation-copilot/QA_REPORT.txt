REAL META DELIVERY
------------------
Not executed because no user Meta access token / Phone Number ID was supplied. This is intentional: secrets were not fabricated or embedded. The exact real-mode code path is present and uses the same server endpoint tested in mock mode, then calls Meta's media + messages endpoints when WHATSAPP_MODE=real is configured.

KNOWN EXTERNAL CONSTRAINT
-------------------------
WhatsApp conversation-window/template policy is enforced by Meta. If the customer conversation requires an approved message template, the direct free-form document send can be rejected by Meta. The adapter returns that real Meta error rather than reporting a false success.
